## Overview

This TP presents the front-end interface of an online perfume store named Parfumi.
The interface is centred on product discovery and a clear shopping experience.
Its visual structure helps users browse perfume items and understand the information attached to each product.

## Main Topics

### Store layout
A consistent storefront layout that gives the product catalogue a clear structure.

### Product catalogue
Product cards that present perfume images, names, and key details.

### Product discovery
Browsing and search elements that help users find a perfume.

### Shopping cart
A cart interface that represents the items selected by the customer.
