# Application screenshots

Save screenshots captured from the frontend-only Parfumi Store application in this folder.

Recommended files:

- `01-storefront.png` - full desktop storefront.
- `02-shopping-cart.png` - cart with quantities and total visible.
- `03-product-search.png` - a search result.
- `04-local-admin.png` - optional local product-management view.

Capture the images after running the project with `npm run dev`. Do not use screenshots of backend dashboards or old full-stack-only workflows as evidence for this frontend-only submission. Hide personal email addresses or other private information before submitting.
